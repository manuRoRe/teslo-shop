# 🛒 Teslo Shop - E-commerce Full Stack

> Una aplicación de comercio electrónico completa, robusta y escalable inspirada en la tienda de Tesla. Desarrollada con arquitectura moderna y enfoque en el rendimiento.

🔗 **Demo Desplegada:** [Ver aplicación en vivo](TU_LINK_AQUI)

## 🚀 Tecnologías Principales

Este proyecto demuestra el dominio de un stack moderno de JavaScript:

* **Frontend:** React, TypeScript, TailwindCSS.
* **State Management:** Zustand (Manejo de estado global ligero y escalable).
* **Data Fetching:** TanStack Query (Caché inteligente y sincronización con el servidor).
* **Backend:** Node.js (REST API).
* **Base de Datos:** MongoDB / PostgreSQL.
* **Infraestructura:** Docker (Contenedorización para desarrollo consistente).

## 💡 Características Destacadas

* **Autenticación JWT:** Sistema seguro de registro y login de usuarios.
* **Carrito de Compras Persistente:** Gestión de estado optimizada para la experiencia de compra.
* **Lazy Loading:** Carga perezosa de módulos para mejorar el tiempo de respuesta inicial.
* **Panel de Administración:** Gestión de productos, inventario y órdenes.
* **Diseño Responsive:** UI adaptada a móviles y escritorio con TailwindCSS.

## 🛠️ Instalación y Configuración (Local)

1. Clonar el repositorio:
   ```bash
   git clone [https://github.com/manuRoRe/teslo-shop.git](https://github.com/manuRoRe/teslo-shop.git)
2. Renombrar el .env.template a .env
3. Ejecutar el comando `npm i` para
   las dependencias
4. Verificar que el backend esta corriendo
   en el puerto 3000 (El backend también
   se encuentra en este Github bajo
   el nombre de nest-teslo-shop-backend, 
   mira el readme.md para ponerlo
   en funcionamiento) 
6. Ejecutar el comando `npm run dev`
   para iniciar el servidor de desarrollo
